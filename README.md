# Unofficial Playing Cards Mod

An unofficial, community-maintained fork of [Playing Cards](https://github.com/OmbreMoon/PlayingCards), originally created by Calemi and OmbreMoon. This project is not affiliated with or endorsed by the original authors.

For Minecraft 26.1.2 with NeoForge 26.1.2.109.

This fork has been modified from the upstream project; this update is dated 2026-09-29.

Adds playing cards, poker chips, and more!

Performance note: The fork is functional, but it is not fully optimized yet; performance may vary.
